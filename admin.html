Giriş

Bu panel, sitenin GitHub deposundaki ayarları değiştirir. Giriş için GitHub'dan bir anahtar (token) gerekir. Bir kere girersin, telefon hatırlar.



Anahtarı nasıl alırım?
  1. github.com'a gir > sağ üst profil resmi > Settings
  2. En altta Developer settings > Personal access tokens > Fine-grained tokens > Generate new token
  3. Token name: orkinos. Expiration: 1 yıl (veya No expiration)
  4. Only select repositories seç, orkinos deposunu işaretle
  5. Permissions > Repository permissions > Contents yanından Read and write seç
  6. Generate token'a bas, çıkan uzun yazıyı kopyala ve yukarıya yapıştır. Bu yazıyı kimseyle paylaşma.
